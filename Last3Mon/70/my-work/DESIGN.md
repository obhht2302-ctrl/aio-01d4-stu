| Notice webhook | 일부 다름 | 경로: `sample-maintenance` · `sample-security` · `sample-training` | 공지 키트의 웹훅 하나로 통합하고 `kind`를 입력받음 |

| Writer agent | 일부 다름 | 머리말: `[점검 안내]` · `[보안 안내]` · `[교육 안내]`; 작성 주의사항과 꼭 넣을 문장도 종류별로 다름 | 머리말·꼭 넣을 문장·주의사항은 설정 표, 공통 작성 흐름은 그대로 |
| OpenAI chat model | 같음 | 없음 (`gpt-4.1-mini`, temperature 0, 같은 Credential) | 그대로 |
| Build draft | 같음 | 없음 (작성 결과를 `draft`로 정리) | 그대로 |
| Rule checks | 일부 다름 | 최대 길이: 600 · 500 · 800자; 꼭 넣을 문장: 없음 · `IT팀은 절대 비밀번호를 묻지 않습니다.` · `신청은 IT 포털에서 할 수 있습니다.` | 검사 로직은 규칙 검사 모듈, 최대 길이·꼭 넣을 문장은 설정 표 |
| Build result | 일부 다름 | `kind`: `maintenance` · `security` · `training` | 입력받은 `kind`와 설정 표를 사용하고 나머지 결과 조립은 그대로 |
| Send result | 같음 | 없음 (`$json`을 JSON으로 응답) | 그대로 |
| 노드 연결 순서 | 같음 | 없음 | 그대로 |

- 보안 공지의 규칙을 하나 고쳐야 한다면, 지금은 **2곳**(`Writer agent`의 작성 지시와 `Rule checks`의 검사 값)을 고쳐야 한다.
